# Competitive Programming

Repositorio de **soluciones en código** para problemas de Programación Competitiva.

Principalmente contiene soluciones de problemas provenientes de:

* **ICPC**
* **Codeforces**
* **CSES**
* **CPC UAEH**

Las soluciones están enfocadas en la práctica de **algoritmos, estructuras de datos y técnicas de resolución de problemas**.

## Lenguaje

Las soluciones están implementadas principalmente en **C++**.

## Plataformas

* [**Codeforces**](https://codeforces.com/)
 *  Plataforma en línea utilizada para la programación competitiva, donde programadores de todo el mundo compiten en la resolución de problemas complejos de matemáticas e informática.

* [**CSES**](https://cses.fi/problemset/)
 * El conjunto de problemas de CSES es una colección de problemas de programación algorítmica creando  una colección completa y de alta calidad para aprender programación algorítmica.

* [**CPC UAEH**](https://cpcjudge.com)
 * Servidor creado y usado por miembros del CLub de Programación Competitiva de la Universidad Autónoma del Estado de Hidalgo 

* [**ICPC**]
 * (International Collegiate Programming Contest) es la competencia de programación algorítmica más antigua, grande y prestigiosa del mundo para estudiantes universitarios. Donde equipos de 3 integrantes tienen 5 horas para resolver un conjunto de 10 a 16 problemas usando lógica y programación con el objetivo de resolver la mayor cantidad en el menor tiempo poisble.
